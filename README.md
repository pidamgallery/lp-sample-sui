# SUI hair salon — LP制作例

Pidam Galleryが制作した、架空の美容室「SUI hair salon」のランディングページです。

ランサーズのLP制作パッケージやポートフォリオで、制作可能なデザインとページ構成を具体的に紹介するためのサンプルとして制作しました。

## 大切な表記

- 店舗名、人物、住所、料金、営業時間はすべて架空です。
- 掲載写真は、この作成例のために用意したオリジナルのAI生成画像です。
- 予約ボタンはサンプル表示であり、実在する予約先には接続していません。
- 実在する店舗・人物・サービスとは関係ありません。

## デザイン

- コンセプト：静かな大人向け美容室
- 基調色：アイボリー `#F6F2EB`、深いグリーン `#53665A`
- アクセント：ワインレッド `#7A3F4B`
- パソコンとスマートフォンの表示に対応

## ローカルでの確認

Node.js 22.13.0以上が必要です。

```bash
npm install
npm run dev
```

動作確認用の構築：

```bash
npm run build
```
